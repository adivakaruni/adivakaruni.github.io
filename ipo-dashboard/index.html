Coverage and provenance

Method. A scheduled GitHub Action sweeps EDGAR full-text search for 424B4 final prospectuses containing "has been no public market", fetches each cover page for the offer price, ticker and exchange, then pulls the last preliminary prospectus for the filed range and the first public registration date. SPACs and blank-cheque vehicles are identified and excluded. First-day returns come from the first close on or after pricing. The European panel has no filing-index equivalent and is assembled deal by deal, with a source link per row; unverified rows are excluded from the headline statistics. Parsing is unit-tested against real prospectus text, but any automated read of prose can misfire — the prospectus link on every row is there so a number can be checked in seconds.
